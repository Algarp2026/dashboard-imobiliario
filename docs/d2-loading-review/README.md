# Galeria D/D2 antes/depois

Capturas reais de Chromium com dados exclusivamente ficticios e rede externa bloqueada. Base `54dfd0a` versus esta branch. Nenhuma escrita comercial no teste visual. As 144 imagens cobrem 18 vistas em quatro formatos, nas duas fases.

Desktop 1440x900; portatil 1366x768; tablet 820x1080; mobile 390x844. Os ficheiros `results.json` registam ausencia de erros, overflow e escritas, bem como cache/revisao preservadas.
