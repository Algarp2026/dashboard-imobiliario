Pasta plantas atualizada para o site The View.

Como usar:
1. Substitua a pasta plantas/ atual no GitHub por esta pasta.
2. Garanta que plantas-manifest.json fica dentro de plantas/.
3. Faça deploy no Vercel e hard refresh (Ctrl+F5).

Inclui PDFs originais atualizados e JPGs renderizados para o PDF de proposta cliente.
